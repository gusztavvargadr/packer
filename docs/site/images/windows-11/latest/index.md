### Versions

#### 2607.1.0

[Downloads][BoxVersion260710]

This version provides AMD64 artifacts for Hyper-V, libvirt, VirtualBox and VMware, plus ARM64 artifacts for VirtualBox and VMware. On AMD64, it is an alias of [Windows 11 Version 25H2 Enterprise 2607.1.0]({{ site.baseurl }}{% link images/windows-11/25h2-enterprise/index.md %}#260710); on ARM64, it is an alias of [Windows 11 Version 25H2 Professional 2607.1.0]({{ site.baseurl }}{% link images/windows-11/25h2-professional/index.md %}#260710). It reuses the component evidence from those canonical versions.

[BoxVersion260710]: https://portal.cloud.hashicorp.com/vagrant/discover/gusztavvargadr/windows-11/versions/2607.1.0
